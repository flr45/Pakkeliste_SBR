# SBR Operativ Portal

## Formål
Samle køretøjer, rum, pakkelister, læringsvideoer, SOP'er og operative dokumenter i én mobilvenlig portal for Slagelse Brand og Redning.

## Version 1
- Mobilvenlig forside
- Køretøjsoversigt
- Rum og pakkelister
- Søgning
- Dokumenter og billeder
- QR-links
- Videoakademi
- Videnbank
- Favoritter
- Administration

## Etaper
1. Nyt design og navigation
2. Udvidede køretøjsdata og billeder
3. Udstyrssider og global søgning
4. Videoakademi og dokumentbibliotek
5. QR-koder og favoritter
6. Offline/PWA og køretøjskontrol
